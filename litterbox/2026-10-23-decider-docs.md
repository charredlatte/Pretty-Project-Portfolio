## Findings

- **`harness/README.md` said a model id selects a local Laya. It does not.** The sentence read "Clef on Workers AI inside the free plan, Jev itself, or a local Laya, the model id being the switch". `decide.js`'s header separates the two cases: a model id is the only difference between **Clef and Jev**, both answered through the Worker's `AI` binding, while a local Laya is the **`DECIDE_URL`** branch instead. An operator following that sentence would set `DECIDE_MODEL` and never reach their own server. Pre-existing, not introduced by these pull requests; corrected in #146.

- **The decider was a row in the driver table.** `docs/engine.md` listed "Typed decisions (yes/no, a choice, a score) | Workers AI on the gateway, or any server in `DECIDE_URL` | Built" as the last row of its **Driver** table. It was also redundant: "What is already built" already carries the decider. Removed in #147, with a one-line note under the table so the answer sits where the question arises.

- **`README.md` named a function that does not exist, and the claim around it was also wrong.** It read "the command it builds is one function, `Turn.args()`, and another CLI means writing that function for it once". There is no `Turn` class in `harness/runner/queen.py` — the classes are `Gateway` (103) and `Runner` (115), and `args()` is at 247. "One function" is wrong too: `Runner.turn()` parses Claude Code's `--output-format stream-json` schema, `mcp_file()` writes Claude's `mcpServers` shape where Codex takes TOML, and `main()` resolves only `claude` and exits without it. Both halves corrected in #147. Worth noting because this sentence is what prompted the original question, so the docs had been teaching the misconception.

- **`docs/engine.md` states the decider's price-lock rationale three times, with three different owners.** Lines ~38, ~72 and ~146, and only one of the three mentions `DECIDE_KEY`. When the model is locked, all three must change together. #147 removed the copy it had added rather than reconciling the other two, so the duplication stands. Of a piece with the documentation-surface audit of the same day, which found the README re-walking what `harness/gateway/README.md` and `harness/runner/README.md` own.

- **GitHub's Claude integration still appends its footer to every new pull request here, and it has to be edited off by hand each time.** It did so on both #146 and #147; each was stripped and read back clean. The house rule and `CLAUDE.md` both already say to do this, so nothing is broken — but it is two extra round trips per pull request on a public repo, every time.
